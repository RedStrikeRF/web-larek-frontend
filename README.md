## Описание

Этот проект представляет собой систему для управления каталогом товаров и корзиной покупок. Основные компоненты включают модели для каталога товаров и корзины, а также типы данных, используемые для представления товаров, корзины, заказов и других сущностей.

## Структура

### Модели

#### `CatalogModel`

Модель для управления каталогом товаров. Реализует интерфейс `IItemsModel`.

**Методы:**
- `updateItems(items: Item[]): void` — Обновляет список товаров в каталоге и эмитирует событие об изменении каталога.
- `findItemById(id: string): Item | undefined` — Ищет товар по его ID в каталоге.

#### `BasketModel`

Модель для управления корзиной товаров. Реализует интерфейс `IBasketModel`.

**Методы:**
- `push(item: BasketItem): void` — Добавляет товар в корзину.
- `remove(id: string): void` — Удаляет товар из корзины.
- `clear(): void` — Очищает корзину.
- `getItems(): BasketItem[]` — Возвращает текущий список товаров в корзине.

### Типы данных

#### `Item`

Тип данных для товара в каталоге.
- **id (string)** — Уникальный идентификатор товара.
- **title (string)** — Название товара.
- **description (string)** — Описание товара.
- **category (string)** — Категория товара.
- **price (number | null)** — Цена товара, может быть `null`, если цена не указана.
- **img (string)** — Ссылка на изображение товара.

#### `ItemsList`

Тип данных для списка товаров.
- **items (Item[])** — Массив товаров, поступающих с сервера.

#### `BasketItem`

Тип данных для товара в корзине.
- **id (string)** — Уникальный идентификатор товара.
- **title (string)** — Название товара.
- **count (number)** — Количество товара в корзине.
- **price (number | null)** — Цена товара, может быть `null`, если цена не указана.

#### `OrderForm`

Тип данных для формы заказа.
- **phone (string)** — Номер телефона покупателя.
- **email (string)** — Электронная почта покупателя.
- **payment (string)** — Способ оплаты.
- **address (string)** — Адрес доставки.
- **total (string | number)** — Итоговая сумма заказа.
- **items (string[])** — Список ID товаров в заказе.
